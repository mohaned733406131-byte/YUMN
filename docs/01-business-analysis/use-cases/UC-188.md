# UC-188 — Unpublish a Product (Withdraw from Sale)

## Header Info
- **Use Case ID:** UC-188
- **Title:** Unpublish a Product (Withdraw from Sale)
- **Actor:** Vendor (ACT-02)
- **Trigger:** The vendor stops selling a product without deleting it
- **Priority:** P1
- **Goal:** Set the product to `INACTIVE` so it leaves search and the storefront while data and stock are preserved.
- **Preconditions:** Product belongs to the vendor's store — store_id scoping per BR-VND-07; role Editor/Manager/Owner; product currently `ACTIVE`.

## Main Scenario
1. Vendor opens the product → client `GET /store/products/{id}` (`API-CAT-007`) shows `status: ACTIVE` with its images and stock.
2. Vendor selects Unpublish → client `POST /store/products/{id}/unpublish` (`API-CAT-011`).
3. System sets `status = INACTIVE` → the product disappears from search and storefront because only `ACTIVE` products are listed (BR-CAT-06).
4. System enqueues the catalog index job so the search index drops the product; category browsing stays authoritative during the index lag.
5. Existing orders are unaffected and stock rows are retained for a future re-listing.

## Alternative Scenarios
- **A1 — Re-list later:** the vendor fixes the reason for withdrawal and publishes again (UC-017 step5 — publish path only).
- **A2 — Unpublish mid-promotion:** price and promotion data are retained and simply hidden until republished.

## Exception Scenarios
- **E1 — Another store's product id:** cross-store access denied → `404 NOT_FOUND`.
- **E2 — Store suspended:** `STORE_SUSPENDED` → the withdrawal cannot be performed while the store is suspended.
- **E3 — Repeat call:** the status set is idempotent → the response again reports `INACTIVE` with no adverse effect.

## Postconditions
- Product is `INACTIVE` and excluded from all public reads and search (BR-CAT-06).
- Catalog content, images, and stock records remain intact for future republishing.

## Business Rules Applied
- BR-CAT-06

## Related Requirements
- FR-004 (Product Catalog Management)
- Cross-reference: rel UC-017 step5 (publish only).

## Permissions / Data / External Dependencies
- **Permissions:** Editor/Manager/Owner on own-store products only (BR-VND-07).
- **Data involved:** product row (status), search index entry, stock rows, order line items.
- **External dependencies:** background catalog index job queue; storefront/search cache.

## Acceptance Criteria
- **AC-UC188-01:** Given an `ACTIVE` product, when unpublished, then `status` becomes `INACTIVE` and success is returned.
- **AC-UC188-02:** Given an `INACTIVE` product, when searched or browsed, then it is excluded (BR-CAT-06).
- **AC-UC188-03:** Given another store's product id, when unpublished, then `404 NOT_FOUND` (cross-store access denied).
- **AC-UC188-04:** Given existing orders containing the product, when unpublished, then those orders remain unaffected.
