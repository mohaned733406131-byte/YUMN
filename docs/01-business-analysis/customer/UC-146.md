# UC-146 — View Active Device Sessions

## Header Info
- **Use Case ID:** UC-146
- **Title:** View Active Device Sessions
- **Actor:** Customer (ACT-01)
- **Trigger:** Customer opens Account → Security → Sessions
- **Priority:** P2
- **Goal:** Show the customer every active device session so unfamiliar ones can be recognized and revoked.
- **Preconditions:** Customer authenticated with at least one active session (FR-003).

## Main Scenario
1. Client calls `GET /auth/sessions` (API-ATH-011) for the signed-in customer.
2. System returns the bounded list (≤5 rows, BR-AUTH-06): `sessionId`, `deviceName`, `ipMasked`, `createdAt`, `lastSeenAt`, `current` flag — a small single-page list, no pagination.
3. Customer reviews the rows; the device in use is the one flagged `current: true`.
4. An unrecognized device is handled by revoking it (UC-147) — this use case is read-only.

## Alternative Scenarios
- **A1 — Fewer than five sessions:** the cap is a maximum; the list simply shows the sessions that exist.
- **A2 — Oldest session evicted:** a sixth login removed the oldest session (BR-AUTH-06); it no longer appears and its next request fails.

## Exception Scenarios
- **E1 — Stale list after a concurrent logout or login:** customer refreshes; the next read reflects the current registry.
- **E2 — Expired access token:** `AUTH_INVALID` → client rotates the token pair and re-fetches the list.

## Postconditions
- Success: session list displayed; no session state changed (read-only).
- Failure: no list rendered; sessions unchanged.

## Business Rules Applied
- BR-AUTH-06

## Related Requirements
- FR-003 (User & Profile Management)

## Permissions / Data / External Dependencies
- **Permissions:** authenticated customer reading only their own sessions; IP is masked in every row.
- **Data involved:** session registry rows (device name, masked IP, timestamps).
- **External dependencies:** none.

## Acceptance Criteria
- **AC-UC146-01:** Given six logins from six devices, when the list is read, then at most five sessions are returned and the oldest login's session is absent (BR-AUTH-06).
- **AC-UC146-02:** Given the current device among them, when rendered, then exactly one row carries `current: true`.
- **AC-UC146-03:** Given a session belonging to another customer, when requested, then it is never returned.
