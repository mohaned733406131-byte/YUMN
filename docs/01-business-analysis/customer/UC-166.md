# UC-166 — Edit a Review Once Within 7 Days

## Header Info
- **Use Case ID:** UC-166
- **Title:** Edit a Review Once Within 7 Days
- **Actor:** Customer (ACT-01)
- **Trigger:** Customer opens their own review and chooses Edit
- **Priority:** P2
- **Goal:** Allow the review author exactly one edit of their review within 7 days of creation, keeping one review per order item.
- **Preconditions:** Authenticated; customer authored the review; review exists and is not hidden; within 7 days of creation and the edit allowance not yet consumed (BR-REV-02).

## Main Scenario
1. Customer opens their review from the product page or their order → Edit action is offered while inside the 7-day window.
2. System checks ownership and the single-edit allowance (BR-REV-02).
3. Customer changes rating, comment, and/or images → `PATCH /reviews/{id}` (API-CAT-018).
4. System applies the change and consumes the single edit; the review remains one-per-order-item.
5. The product rating summary refreshes and the updated content replaces the previous version in the feed.

## Alternative Scenarios
- **A1 — Edit inside the window:** `200 { ...review }` with the new content; the allowance is now spent.
- **A2 — Partial edit:** only `rating` or only `comment` is supplied — omitted fields stay unchanged.
- **A3 — Edit affordance after the window:** the UI hides Edit; the API rejects direct calls (see E1).

## Exception Scenarios
- **E1 — Window closed or edit already used:** `REVIEW_EDIT_WINDOW_CLOSED`; original content unchanged (BR-REV-02).
- **E2 — Another user's review:** `NOT_FOUND` (author scope).
- **E3 — Invalid payload:** rating outside 1–5, too many/too-large images → `VALIDATION_ERROR`; nothing persisted (BR-REV-02).

## Postconditions
- Success: exactly one edit recorded for the review; new content live; aggregates refreshed.
- Failure: review content byte-for-byte unchanged; edit allowance not consumed by a rejected call.

## Business Rules Applied
- BR-REV-02

## Related Requirements
- FR-006 (Reviews & Ratings — single edit within 7 days)

## Permissions / Data / External Dependencies
- **Permissions:** only the author may edit; nobody (including vendor) edits customer reviews.
- **Data involved:** review row (rating, comment, images), product rating aggregate.
- **External dependencies:** catalog service (B02); background rating recompute job.

## Acceptance Criteria
- **AC-UC166-01:** Given a 3-day-old never-edited review, when `PATCH /reviews/{id}` is called, then `200` and the new content is live (BR-REV-02).
- **AC-UC166-02:** Given a review already edited once, when `PATCH` is called again, then `REVIEW_EDIT_WINDOW_CLOSED` (BR-REV-02).
- **AC-UC166-03:** Given an 8-day-old review, when `PATCH` is called, then `REVIEW_EDIT_WINDOW_CLOSED` (BR-REV-02).
- **AC-UC166-04:** Given a foreign review id, when `PATCH` is called, then `NOT_FOUND`.
