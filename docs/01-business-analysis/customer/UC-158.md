# UC-158 — Read Static Content and Help Pages

## Header Info
- **Use Case ID:** UC-158
- **Title:** Read Static Content and Help Pages
- **Actor:** Customer (ACT-01)
- **Trigger:** Customer opens a footer or help link (terms, privacy, about, FAQ topic)
- **Priority:** P2
- **Goal:** Render a published CMS page in the active locale without exposing drafts.
- **Preconditions:** Content routes `/{locale}/page/{page-slug}` and `/{locale}/help/*` are public (routing.md §2); pages are authored and published by admins (FR-019).

## Main Scenario
1. Client calls `GET /pages/{slug}` (API-CNT-001) for the opened link.
2. System returns the published page: bilingual `title { ar, en }`, `bodyBlocks`, `publishedAt`, `updatedAt`.
3. Client renders the blocks in the current locale — Arabic default, English parity, Arabic source as fallback (BR-PLT-05).
4. The response is cacheable (`max-age=60`, stale-while-revalidate) so repeat visits stay fast.

## Alternative Scenarios
- **A1 — Page family:** terms, privacy, about and help topics all resolve through the same endpoint — one CMS type, no per-page code.
- **A2 — English field missing:** the Arabic source block renders while the parity gap is closed by the content team (BR-PLT-05).

## Exception Scenarios
- **E1 — Unpublished or archived slug:** `404` — drafts are never readable from the public route (FR-019).
- **E2 — Page just edited:** stale cache up to 60 s, then revalidation serves the new content.

## Postconditions
- Success: published page content rendered in the active locale (read-only).
- Failure: locale-aware 404 shown; no content or state changed.

## Business Rules Applied
- BR-PLT-05

## Related Requirements
- FR-019 (Content & Promotions)

## Permissions / Data / External Dependencies
- **Permissions:** public read of PUBLISHED pages only; authoring and publishing are admin-only.
- **Data involved:** CMS page rows (slug, bilingual title, body blocks, status).
- **External dependencies:** page cache.

## Acceptance Criteria
- **AC-UC158-01:** Given a published bilingual page, when opened with locale = en, then the English title and body render (BR-PLT-05).
- **AC-UC158-02:** Given an unpublished page slug, when requested, then 404 returns with no draft leakage.
- **AC-UC158-03:** Given an unknown slug, when visited, then the locale-aware 404 page renders with search and home links (`routing.md` §9).
