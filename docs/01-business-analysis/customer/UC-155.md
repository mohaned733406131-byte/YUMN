# UC-155 — Browse the Personalized Home Feed

## Header Info
- **Use Case ID:** UC-155
- **Title:** Browse the Personalized Home Feed
- **Actor:** Customer (ACT-01)
- **Trigger:** Customer opens the home route after signing in
- **Priority:** P1
- **Goal:** Assemble banners, promotions, featured categories and followed-store highlights into one localized home payload.
- **Preconditions:** Home route `/{locale}` reachable by guest and customer (routing.md §2); personalization applies only when authenticated (FR-019, FR-009).

## Main Scenario
1. Client calls `GET /home?surface=CUSTOMER` (API-CNT-002).
2. System returns hero banners (scheduled and targeted), active promotions, featured categories, and a `followFeed` of followed stores with new-product counts — the personalized slice exists only for authenticated customers.
3. Labels render in the active locale — Arabic default, English parity (BR-PLT-05).
4. Customer taps a banner, promotion, category or followed-store item → navigates to the target route with the locale prefix preserved.
5. The payload is cacheable (`max-age=60`, stale-while-revalidate) so home stays fast while staying near-live.

## Alternative Scenarios
- **A1 — Guest visit (`surface=GUEST`):** banners, promotions and categories only; no `followFeed`.
- **A2 — Customer following no store:** `followFeed` is empty; merchandising content still renders.

## Exception Scenarios
- **E1 — Admin edited content during cache life:** stale copy serves up to 60 s, then revalidation picks up the change (FR-019).
- **E2 — Invalid `surface` value:** `VALIDATION_ERROR` → client falls back to the default surface.

## Postconditions
- Success: localized home payload rendered for the caller's role; no state changed (read-only).
- Failure: cached or empty-state home shown; customer can retry.

## Business Rules Applied
- BR-PLT-05

## Related Requirements
- FR-019 (Content & Promotions), FR-009 (Search & Discovery)

## Permissions / Data / External Dependencies
- **Permissions:** public read; personalization fields appear only for the authenticated caller.
- **Data involved:** banner schedule/targeting rows, promotion rows, category tree, customer follow relations.
- **External dependencies:** CDN/page cache for the near-live feed.

## Acceptance Criteria
- **AC-UC155-01:** Given an authenticated follower of store X, when home loads, then `followFeed` includes X with its new-product count.
- **AC-UC155-02:** Given a guest visit, when home loads, then no personalized `followFeed` is returned.
- **AC-UC155-03:** Given locale = ar, when home renders, then banner and promotion labels come from the Arabic fields (BR-PLT-05).
