# UC-156 — Use Search Suggestions (Typeahead)

## Header Info
- **Use Case ID:** UC-156
- **Title:** Use Search Suggestions (Typeahead)
- **Actor:** Customer (ACT-01)
- **Trigger:** Customer types into the search box on web or mobile
- **Priority:** P2
- **Goal:** Offer up to 10 prefix-based product, category and store suggestions while the customer types.
- **Preconditions:** Search surface reachable by guest and customer (`/{locale}/search`, routing.md §2); index serves ACTIVE products only (BR-CAT-06).

## Main Scenario
1. Once the query passes the minimum length, a debounced `GET /search/suggest?q=&limit≤10` fires (API-SRC-003).
2. System returns Arabic-normalized, prefix-oriented suggestions with `{ text, type, slug, count? }` — no facets, no cursor (FR-009).
3. Only ACTIVE products appear; soft-deleted or unpublished items never surface (BR-CAT-06).
4. Customer taps a suggestion → navigates to the entity page or to the full result list; filters, sorting and pagination belong to UC-006.

## Alternative Scenarios
- **A1 — Below minimum query length:** `QUERY_TOO_SHORT` → no request is sent and no list appears.
- **A2 — Explicit full search:** pressing Enter always runs the full search (UC-006); typeahead is advisory only.

## Exception Scenarios
- **E1 — Index degraded:** `SEARCH_UNAVAILABLE` with `meta.degraded` set → UI keeps accepting input and falls back to the full search path (UC-006).
- **E2 — Network error:** suggestions are skipped silently; submitting the query still reaches full search.

## Postconditions
- Success: suggestion list shown or safely omitted; no cart, order or index state changed (read-only).
- Failure: customer continues to the full search with the same query.

## Business Rules Applied
- BR-CAT-06

## Related Requirements
- FR-009 (Search & Discovery)
- Cross-reference: rel UC-006 step (full search with filters) — this UC covers the typeahead suggestion leg only (API-SRC-003).

## Permissions / Data / External Dependencies
- **Permissions:** public read; suggestions expose only storefront-visible entities (BR-CAT-06).
- **Data involved:** search index documents (products, categories, stores) with slugs.
- **External dependencies:** search service behind `GET /search/suggest`.

## Acceptance Criteria
- **AC-UC156-01:** Given a soft-deleted product, when suggestions are queried, then it never appears (BR-CAT-06).
- **AC-UC156-02:** Given an Arabic query prefix, when requested, then normalized Arabic matches are returned in the current locale.
- **AC-UC156-03:** Given a suggestion tap, when navigated, then the target page opens under the same locale prefix.
