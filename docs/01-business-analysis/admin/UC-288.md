# UC-288 — Run the GMV Report

## Header Info
- **Use Case ID:** UC-288
- **Title:** Run the GMV Report
- **Actor:** Admin (ACT-04)
- **Trigger:** Leadership or finance needs gross merchandise value for a period, by segment, to size the business
- **Priority:** P2
- **Goal:** Produce platform GMV figures for a date range with an honest exact/estimate label on every money total.
- **Preconditions:** Report family `gmv` exists on the admin report endpoint (API-ANL-007); Admin holds analytics read (FR-018); date range supplied.

## Main Scenario
1. Admin requests `GET /admin/reports/gmv` with `?from&to&page&pageSize&groupBy?` (API-ANL-007).
2. System aggregates gross value for the range and returns columns, paged rows, totals and `totalsMeta`.
3. Admin reads the annotation: `gmv` is a heavy family and may report `relation: "estimate"` before the nightly backfill lands, `exact` after.
4. Admin compares against the headline dashboard figure (`GET /admin/dashboard`, API-ANL-006) for consistency.
5. Admin exports CSV when stakeholders need the file (`GET /admin/reports/gmv/export`, API-ANL-008), respecting the 50,000-row cap.

## Alternative Scenarios
- **A1 — Post-backfill run:** the nightly job has completed → totals return `relation: "exact"` and the figure is ledger-sourced.
- **A2 — Segmented view:** `groupBy` slices GMV (e.g. by day or vendor band) for trend analysis; labels stay attached per total.
- **A3 — Moderator viewing:** Moderator reads the table but cannot export (API-ANL-008).

## Exception Scenarios
- **E1 — Unknown family or bad range:** `VALIDATION_ERROR` → no figures returned (API-ANL-007).
- **E2 — Export over the cap:** `LIMIT_EXCEEDED` → no partial CSV; Admin narrows the range (API-ANL-008).
- **E3 — Rollup stale beyond its window:** freshness is reported rather than silently serving old numbers — the report never presents a stale total as current.

## Postconditions
- Success: Admin holds GMV for the requested period with every total labelled exact or estimate; all endpoints are reads — no financial record changed.
- Failure: no partial or unlabelled figure is produced.

## Business Rules Applied
- BR-FIN-02 (order totals that GMV sums — items + VAT + shipping per sub-order)

## Related Requirements
- FR-018 (Analytics & Reporting)
- FR-020 (Platform Administration, Settings & Audit)

## Permissions / Data / External Dependencies
- **Permissions:** Admin (ACT-04) report + export; Moderator report read only (API-ANL-007/008).
- **Data involved:** GMV aggregates, per-period totals, `totalsMeta` labels (read).
- **External dependencies:** pre-aggregation rollups + nightly backfill; append-only ledger for exact money (block B07).

## Acceptance Criteria
- **AC-UC288-01:** Given a valid range, when the `gmv` report is requested, then columns, paged rows and totals are returned (API-ANL-007).
- **AC-UC288-02:** Given a pre-backfill run, when totals are read, then they are labelled `estimate` — never presented as exact.
- **AC-UC288-03:** Given the nightly backfill has run, when the report is re-run, then totals are labelled `exact`.
- **AC-UC288-04:** Given an Admin export within the cap, when it is made, then the CSV matches the on-screen report (API-ANL-008).
