# UC-104 — List CMS Pages

## Header Info
- **Use Case ID:** UC-104
- **Title:** List CMS Pages
- **Actor:** Admin (ACT-04) — content scope
- **Trigger:** Admin opens Content → Pages in the console
- **Priority:** P2
- **Goal:** See all CMS pages with slug, bilingual title and publish status to decide what to edit or publish next.
- **Preconditions:** Admin or Moderator authenticated with page-list access (API-CNT-005); pages may or may not exist yet.

## Main Scenario
1. Admin opens the page list → `GET /admin/pages?page=&pageSize=&status=&sort=updatedAt_desc` (API-CNT-005).
2. System returns offset-paginated rows: id, slug, title (ar/en), status `DRAFT`/`PUBLISHED`, updatedAt.
3. Titles carry both locales with Arabic as default and English parity (BR-PLT-05); the admin surface itself is localized the same way.
4. Admin filters `status=DRAFT` to review unpublished content, then drills into a page to edit (UC-106) or publish (UC-107).
5. The listing is read-only (FR-019).

## Alternative Scenarios
- **A1 — Moderator read:** Moderator lists pages (API-CNT-005 roles) without create or publish rights.
- **A2 — Status filter:** Isolate drafts or published pages for editorial review.

## Exception Scenarios
- **E1 — Permission denied:** Non-staff session → `403 FORBIDDEN`.
- **E2 — No pages yet:** Fresh install → zero rows with an empty state and HTTP 200.
- **E3 — Concurrent edit:** Another admin updates a page while the list is open → `updatedAt` shows the stale value until refresh.
- **E4 — Locale gap:** A title missing one locale is flagged for completion before publish (BR-PLT-05 ar default, en parity).

## Postconditions
- The page list reflects request-time state; no content was mutated (FR-019).
- A page is selected for edit, publish or archive.

## Business Rules Applied
- BR-PLT-05

## Related Requirements
- FR-019 (Content & Promotions — CMS + Coupons)

## Permissions / Data / External Dependencies
- **Permissions:** `ADMIN`/`MODERATOR` read; writes belong to UC-105, UC-106, UC-107, UC-108.
- **Data involved:** CMS page headers (slug, bilingual title, status); bodies load on the detail view.
- **External dependencies:** Content service (B12); locale resolution (`ar` default).

## Acceptance Criteria
- **AC-UC104-01:** Given pages in both statuses, when listed, then rows return with slug, ar/en title and status.
- **AC-UC104-02:** Given a draft-only filter, when applied, then only `DRAFT` pages return.
- **AC-UC104-03:** Given zero pages, when listed, then HTTP 200 returns with an empty state.
- **AC-UC104-04:** Given a non-staff session, when requested, then `403 FORBIDDEN` is returned.
