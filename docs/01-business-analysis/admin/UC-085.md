# UC-085 — Run a Platform Report

## Header Info
- **Use Case ID:** UC-085
- **Title:** Run a Platform Report
- **Actor:** Admin (ACT-04) — reporting scope
- **Trigger:** Admin opens Analytics → Reports and picks a report family
- **Priority:** P1
- **Goal:** Produce a paginated, filterable tabular report over platform data for a chosen family and period.
- **Preconditions:** Admin (or Moderator for read) authenticated with report access (API-ANL-007); families available: `orders`, `gmv`, `vendors`, `delivery`, `returns`, `kyc`, `users`.

## Main Scenario
1. Admin selects family, period and grouping → client `GET /admin/reports/{family}?from=&to=&page=&pageSize=&groupBy=` (API-ANL-007).
2. System validates the family and returns columns, rows, offset pagination and totals metadata (exact vs estimate).
3. Data comes from pre-aggregated rollups (BR-PLT-01, queue `b11.analytics.rollup`); reads are idempotent — the same query returns the same figures.
4. Admin pages, sorts and filters the table; every change is a fresh read of the same dataset (FR-018).
5. When a file is needed, Admin hands off to CSV export (UC-086).

## Alternative Scenarios
- **A1 — Grouped aggregation:** `groupBy` collapses rows into period aggregates before paging.
- **A2 — Moderator run:** Moderator runs the same report read but is excluded from the export path (UC-086).

## Exception Scenarios
- **E1 — Permission denied:** Non-staff session → `403 FORBIDDEN`.
- **E2 — Unknown family:** `VALIDATION_ERROR` returned; no partial rows are rendered.
- **E3 — Concurrent state change:** Rows shift between page requests → offset paging reflects request-time data; totals re-read on refresh.
- **E4 — Rollup not yet backfilled:** Heavy families (`gmv`, `delivery`) are labelled estimate until the nightly job lands; the report never invents numbers.

## Postconditions
- The report is rendered for the requested family/period; no data mutated (read-only endpoint).
- Admin can continue to export (UC-086) or drill into the source queues.

## Business Rules Applied
- BR-PLT-01

## Related Requirements
- FR-018 (Analytics & Reporting)

## Permissions / Data / External Dependencies
- **Permissions:** `ADMIN`/`MODERATOR` read on reports; export is `ADMIN` only; no write scope.
- **Data involved:** Read-only report rows over the append-only ledger and order history; no cross-store mixing.
- **External dependencies:** BullMQ rollup queue `b11.analytics.rollup` (BR-PLT-01).

## Acceptance Criteria
- **AC-UC085-01:** Given family `orders` and a date range, when requested, then columns and rows return with offset pagination.
- **AC-UC085-02:** Given an unknown family, when requested, then `VALIDATION_ERROR` returns and no rows are produced.
- **AC-UC085-03:** Given a non-admin session, when the endpoint is called, then `403 FORBIDDEN` is returned.
- **AC-UC085-04:** Given identical filters run twice, when compared, then both responses carry identical figures.
