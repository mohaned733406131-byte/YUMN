# UC-415 — Browse Completed Jobs in the History Tab

## Header Info
- **Use Case ID:** UC-415
- **Title:** Browse Completed Jobs in the History Tab
- **Actor:** Delivery Provider (ACT-03)
- **Trigger:** Courier opens the History tab to review past work
- **Priority:** P2
- **Goal:** Give the courier a read-only, cursor-paginated list of their own finished jobs with proof on demand.
- **Preconditions:** Courier authenticated; at least one prior delivery may exist; History tab exists in the S5 tab bar (IA §6).

## Main Scenario
1. Courier taps **History** in the S5 tab bar (Queue · Active · History · Profile).
2. Client calls `GET /deliveries/mine` (API-SHP-002) filtered to completed deliveries — a cursor feed of the courier's own jobs.
3. Rows render store name, drop-off district, state badge, offered fee and a link to detail; scrolling appends the next cursor page.
4. Tapping a row opens read-only job detail with the proof: code verification, timestamp and optional photo (BR-SHP-07).
5. Nothing in this tab mutates anything — it is a pure read surface.

## Alternative Scenarios
- **A1 — Empty history:** the empty state appears with a Refresh recovery action (screen-states §3).
- **A2 — Filter by past state:** the same feed is filtered; ownership scope is unchanged.
- **A3 — Offline:** the cached page renders behind the offline banner and refreshes on reconnection.

## Exception Scenarios
- **E1 — Feed failure:** page error with retry plus queue fallback (screen-states §4).
- **E2 — A row no longer belongs to this courier:** the server hides it / returns not-found and the list re-renders (BR-ORD-09).
- **E3 — Cursor expired or malformed:** `VALIDATION_ERROR` → the feed restarts from the first page with no duplicates.

## Postconditions
- Success: courier reviews own completed work with proof detail, read-only.
- Failure: nothing written — list and job state are unchanged.

## Business Rules Applied
- BR-ORD-09, BR-SHP-07

## Related Requirements
- FR-015 (Shipping & Delivery)
- **Related:** History tab of the S5 IA (IA §6) — complements UC-405 (aggregate stats) with per-job detail.

## Permissions / Data / External Dependencies
- **Permissions:** courier reads only own deliveries (BR-ORD-09); admin dispatch is a separate view.
- **Data involved:** shipment list (own), proof records, cursor pagination state.
- **External dependencies:** delivery API; no location data is requested or stored (C-16).

## Acceptance Criteria
- **AC-UC415-01:** Given completed jobs, when History opens, then only this courier's jobs are listed (BR-ORD-09).
- **AC-UC415-02:** Given more rows than one page, when scrolled, then the next cursor page appends without duplicates.
- **AC-UC415-03:** Given a row tapped, when detail opens, then proof shows code verification, timestamp and the optional photo (BR-SHP-07).
- **AC-UC415-04:** Given an empty history, when the tab opens, then an empty state with a recovery action is shown.
