# TC-011 — Cross-user access to another customer's order or address is denied

| Field | Value |
|---|---|
| Objective | Verify that a customer acting on another customer's order, address or session resource is denied server-side with no data disclosure, regardless of what the UI shows. |
| Level | integration |
| Priority | P0 (merge-blocking, also runs under SEC-P-05) |
| Automation | Yes — Jest + Supertest |

## Preconditions
- Customer A `771234567` and customer B `731234567` both hold valid access tokens.
- Order `ORD-9001` belongs to B (state `PLACED`, total 12,500 YER); address `ADR-B1` belongs to B; session `sess_B1` belongs to B.
- Both callers send direct API calls — no frontend involved.

## Test Data

| Field | Value |
|---|---|
| Attacker token | Customer A (`771234567`) |
| Victim order | `ORD-9001` (owner B) |
| Victim address | `ADR-B1` (owner B) |
| Victim session | `sess_B1` (owner B) |

## Steps
1. `GET /orders/ORD-9001` with A's token.
2. `GET /orders/ORD-9001/timeline` with A's token.
3. `PUT /addresses/ADR-B1` with A's token and body `{"label":"home","line1":"changed by A"}`.
4. `DELETE /addresses/ADR-B1` with A's token.
5. `DELETE /auth/sessions/sess_B1` with A's token.
6. `GET /orders` (own feed) with A's token and search for `ORD-9001`.
7. Verify B's data after steps 1–6 by reading it with B's own token.

## Expected Result
- Step 1 returns `403 FORBIDDEN` with no order payload (per `AC-FR002-01`); the body never contains B's name, address, items or totals.
- Step 2 returns `403 FORBIDDEN` (or `404 NOT_FOUND` per the IDOR-safe rule) with an empty resource payload.
- Steps 3 and 4 return `404 NOT_FOUND` — the resource is outside A's tenant scope and is indistinguishable from a missing row.
- Step 5 returns `404 NOT_FOUND` — a foreign session can never be revoked.
- Step 6 returns only A's own orders; `ORD-9001` never appears in another user's feed.
- Step 7 proves zero side effects: B's order state, address and session are byte-identical to the pre-test snapshot.
- No response body leaks PII of B; the correlation ID is present for tracing.
