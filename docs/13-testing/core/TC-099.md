# TC-099 — Public home and promotions payloads are cached, localized and privacy-aware

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify that `GET /home` and `GET /promotions` are the contract's cacheable public reads (max-age/ETag), return only active in-window promotions in both locales, and include the `followFeed` personalization slice only when a token is present. | integration | P1 | Yes — Jest + Supertest |

## Preconditions

| # | Precondition |
|---|---|
| 1 | Seeded content: platform coupon `RAMADAN25` (`endsAt` future), an expired coupon `EID2024` (`endsAt` past), a disabled coupon `SUSPENDED10`, store coupon `TECH5` (store `tech-store`), hero banner, featured categories. |
| 2 | Customer `771234567` follows stores `tech-store` (2 new products) and one other store (0 new products); a second customer follows nothing. |
| 3 | Tokens: `CUSTOMER` with locale `ar` (default) and locale `en`; guest with no token. |

## Test Data

| Field | Value |
|---|---|
| guest home | `GET /home?surface=GUEST` (no token) |
| auth home | `GET /home?surface=CUSTOMER` with customer token, `Accept-Language: ar` then `en` |
| promotions | `GET /promotions?scope=PLATFORM&limit=20&cursor=` and `GET /promotions?scope=STORE&storeId=tech-store` |

## Steps
1. Guest: call home twice; inspect `Cache-Control`, `ETag`, `banners`, `promotions`, `categories`, and whether `followFeed` appears.
2. Authenticated customer: call home with `Accept-Language: ar` then `en`; inspect `promotions[].label`, `followFeed`, `banners`.
3. Call `/promotions?scope=PLATFORM` and `scope=STORE`; diff the item sets against the seeded coupons (active/expired/disabled).
4. Replay a response with its `If-None-Match` ETag; send `scope=WORLDWIDE` and `surface=TABLOID`.

## Expected Result
- Step 1 → both calls `200` with `Cache-Control: max-age=60, stale-while-revalidate=300` and an `ETag` (only `API-CNT-001…003` are cacheable, `content.md` §2); `followFeed` key absent for the guest — personalization only when authenticated (`API-CNT-002`, privacy: `SEC-REQ-012`); active `RAMADAN25` appears in `promotions` with `discountPercent` and future `endsAt`.
- Step 2 → `followFeed` present containing `{ storeId, name, newProductCount }` for followed stores only (`BR-VND-05`); `label` renders in `ar` for `Accept-Language: ar` and `en` for `en`, with the user's default `ar` when no header (`BR-NTF-04`, `C-24`); the un-following customer's payload shows an empty/absent slice.
- Step 3 → `scope=PLATFORM` lists only platform-scoped active coupons; `scope=STORE` lists only that store's coupons with `storeId` set; `EID2024` and `SUSPENDED10` appear nowhere (`API-CNT-003`, `BR-PRM-03`, `BR-PRM-04` — expired/disabled excluded).
- Step 4 → `304 Not Modified` on the matching ETag (cache validators); `scope=WORLDWIDE` → `400 VALIDATION_ERROR`, `surface=TABLOID` → `400 VALIDATION_ERROR` (documented enums, `API-CNT-003/002`).
