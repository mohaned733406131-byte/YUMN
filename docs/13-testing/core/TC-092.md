# TC-092 — CSV exports carry BOM, formula-injection guards, the row cap and role gates

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify that report exports stream a UTF-8-BOM CSV whose headers match the report columns, that cells starting with `=`, `+`, `-`, `@` are `'`-prefixed against Excel formula injection, that >50,000 rows are refused with `422 LIMIT_EXCEEDED`, and that Viewer staff and Moderators are locked out of exports. | integration | P1 | Yes — Jest + Supertest |

## Preconditions

| # | Precondition |
|---|---|
| 1 | Store `tech-store` has a product named `=SUM(1,1)` and a customer name `+967799000111` in the sales rows (injection probes); September sales report exists per `TC-091`. |
| 2 | Staff seeded: user `779876550` with role **Viewer** on `tech-store`, owner `779876543` (Manager/Owner); `ADMIN` and `MODERATOR` tokens seeded. |
| 3 | A heavy seed (platform `orders` admin family) holds >50,000 rows for the cap probe. |

## Test Data

| Field | Value |
|---|---|
| vendor export | `GET /store/reports/sales/export?from=2026-09-01&to=2026-09-30` (owner) |
| viewer export | same URL as Viewer `779876550` → expect `403 FORBIDDEN` |
| admin export | `GET /admin/reports/orders/export?from=2026-09-01&to=2026-09-30` (admin / moderator) |
| cap probe | admin `orders` export on the >50k seed → expect `422 LIMIT_EXCEEDED` |

## Steps
1. As owner `779876543`, download the vendor sales export; inspect the first bytes, `Content-Type`, `Content-Disposition` and the header row.
2. Locate the cells for `=SUM(1,1)` and `+967799000111` in the body; compare headers with `GET /store/reports/sales` `columns`.
3. As Viewer `779876550`, request the same export; as `MODERATOR`, request the admin export; as `ADMIN`, request it.
4. As `ADMIN`, request the >50k `orders` export.

## Expected Result
- Step 1 → `200` with `Content-Type: text/csv`, `Content-Disposition: attachment`, body starting with the UTF-8 BOM (`EF BB BF`), one header row plus 12 data rows (`API-ANL-003`, `analytics.md` §1).
- Step 2 → `'=SUM(1,1)` and `'+967799000111` — every cell starting `= + - @` is prefixed with `'` (formula-injection guard, `analytics.md` intro/§1); headers match the report `columns` (localized labels, `AC-FR018-03`, `BR-PLT-05`).
- Step 3 → Viewer → `403 FORBIDDEN` (export requires Manager/Owner, `API-ANL-003`); Moderator admin export → `403 FORBIDDEN` — Moderators are excluded from finance exports (`API-ANL-008`, `analytics.md` §2); Admin → `200 text/csv` with the same BOM/formula rules (`API-ANL-008`, `AC-FR018-03`).
- Step 4 → `422 LIMIT_EXCEEDED` — the 50,000-row cap is enforced (`error-model.md` 422, `analytics.md` §3); repeated downloads are stable pure reads (`analytics.md` §2).
