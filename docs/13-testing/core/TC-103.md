# TC-103 — Public page rendering is bilingual and cached; admin page list filters and pages through drafts

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify that `GET /pages/{slug}` returns a published page with both locales, cache validators and a clean 404 for unknown slugs, and that `GET /admin/pages` filters by status, sorts by `updatedAt` and pages with correct totals for Admin and Moderator. | integration | P2 | Yes — Jest + Supertest |

## Preconditions

| # | Precondition |
|---|---|
| 1 | Published page `privacy-policy` (bilingual title/bodyBlocks), one published page `about-yumn`, two draft pages `faq-v2` and `shipping-policy`; no other pages use these slugs. |
| 2 | Tokens: `ADMIN`, `MODERATOR`; public read needs no token (`API-CNT-001`). |
| 3 | Pages seeded with distinct `updatedAt` values so `sort=updatedAt_desc` is deterministic. |

## Test Data

| Field | Value |
|---|---|
| public reads | `GET /pages/privacy-policy` with `Accept-Language: ar` then `en`; `GET /pages/no-such-page` |
| cache probe | second call with `If-None-Match: <etag>` |
| admin list | `GET /admin/pages?page=1&pageSize=1&status=DRAFT&sort=updatedAt_desc` |

## Steps
1. Anonymous: `GET /pages/privacy-policy` (no `Accept-Language`), then with `ar`, then with `en`; capture `title`, `bodyBlocks`, `publishedAt`, `Cache-Control`, `ETag`.
2. Replay with `If-None-Match`; `GET /pages/no-such-page`.
3. As `ADMIN`, `GET /admin/pages?page=1&pageSize=1&status=DRAFT&sort=updatedAt_desc`; then `pageSize=10` without a filter.
4. As `MODERATOR`, repeat the filtered list; as `CUSTOMER`, `GET /admin/pages`.

## Expected Result
- Step 1 → `200 { slug, title: { ar, en }, bodyBlocks, publishedAt, updatedAt }` — both locale keys always present regardless of header, with the header choosing the display locale and `ar` as default (`BR-NTF-04`, `C-24`, `AC-FR019-04`); `Cache-Control: max-age=60, stale-while-revalidate=300` with an `ETag` (`content.md` §2 — one of the contract's three cacheable reads).
- Step 2 → `304 Not Modified` on the matching ETag; unknown slug → `404 NOT_FOUND` (`API-CNT-001`).
- Step 3 → `200 { items: [ 1 draft ], page: { … }, total }` with exactly one item, newest-first by `updatedAt` (`API-CNT-005`); unfiltered `pageSize=10` returns all 4 pages with `total: 4` and offset math consistent (page 2 of size 1 returns the second-newest).
- Step 4 → Moderator → `200` with identical rows (read parity, `API-CNT-005`, `SEC-REQ-004`); `CUSTOMER` → `403 FORBIDDEN` (admin surface is role-gated, `FR-002`); drafts are visible to staff but never on the public route (covered by `TC-096`).
