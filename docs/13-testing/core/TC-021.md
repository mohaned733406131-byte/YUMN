# TC-021 — Review eligibility: only the purchaser after DELIVERED, within 30 days, once per item

| Field | Value |
|---|---|
| Objective | Verify that `POST /reviews` accepts exactly one review from the purchasing customer within 30 days of `DELIVERED` and rejects every ineligible attempt with the documented error code while storing nothing. |
| Level | integration |
| Priority | P1 |
| Automation | Yes — Jest + Supertest (DELIVERED-order fixtures from DOC-TST-005) |

## Preconditions
- Order fixture `ORD-RV1` (customer `771234567`) is `DELIVERED` 3 days ago; its `orderItemId` `OI-RV1` has no review yet.
- Order fixture `ORD-RV2` is in `CONFIRMED` (not yet delivered) for the same customer.
- Order fixture `ORD-RV3` was delivered 31 days ago (window elapsed).
- Customer `731234567` is registered but did not purchase `ORD-RV1`.
- Each uploaded review image is ≤5 MB, jpg/png/webp, EXIF-stripped.

## Test Data

| Field | Value |
|---|---|
| Eligible order item | `OI-RV1` (owner `771234567`, delivered 3 days ago) |
| Not-yet-delivered item | `OI-RV2` (state `CONFIRMED`) |
| Window-elapsed item | `OI-RV3` (delivered 31 days ago) |
| Valid rating / comment | `5`, `ممتاز وسريع الشحن` |
| Invalid ratings | `0`, `6` |
| Oversized image set | 6 file IDs |

## Steps
1. `POST /reviews` with `{"orderItemId":"OI-RV1","rating":5,"comment":"ممتاز وسريع الشحن"}`.
2. `POST /reviews` with `{"orderItemId":"OI-RV2","rating":5}` (order still `CONFIRMED`).
3. `POST /reviews` with `{"orderItemId":"OI-RV3","rating":5}` (delivered 31 days ago).
4. `POST /reviews` with `{"orderItemId":"OI-RV1","rating":3}` as customer `731234567` (not the purchaser).
5. `POST /reviews` with `{"orderItemId":"OI-RV1","rating":6}` then `{"orderItemId":"OI-RV1","rating":0}`.
6. `POST /reviews` with `{"orderItemId":"OI-RV1","rating":4,"imageFileIds":["f1","f2","f3","f4","f5","f6"]}` (6 images).
7. `POST /reviews` for `OI-RV1` a second time (after step 1 succeeded).
8. `PATCH /reviews/{id}` with `{"rating":4,"comment":"جيد جدا"}` (first edit), then a second `PATCH` with `{"rating":3}`.
9. `GET /products/{slug}/reviews` as an anonymous visitor.

## Expected Result
- Step 1 returns `201 {"status":"PUBLISHED","rating":5,"verifiedPurchase":true}` — eligibility satisfied (`BR-REV-01`).
- Steps 2, 3 and 4 each return `403 REVIEW_NOT_ELIGIBLE` with `details.issue` ∈ {`ORDER_NOT_DELIVERED`, `WINDOW_ELAPSED`, `NOT_PURCHASER`}.
- Step 5 returns `400 VALIDATION_ERROR` with `details[0].field = "rating"` for both bounds; step 6 returns `400 VALIDATION_ERROR` with `details[0].field = "imageFileIds"` (>5 images) or `413`/`415` for a bad file (`BR-REV-03`).
- Step 7 returns `409 REVIEW_ALREADY_EXISTS` — one review per order item (`BR-REV-02`).
- Step 8: first edit returns `200`; the second returns `409 REVIEW_EDIT_WINDOW_CLOSED` (one edit only; backdating past 7 days also closes the window).
- Steps 2–6 and the rejected half of step 8 persist **zero** review rows (`AC-FR006-03`: validation fails and nothing is stored).
- Step 9 lists only the review from step 1 with `verifiedPurchase: true`, localized RTL rendering and a correct `ratingSummary`.
