# TC-094 — Admin dashboard aggregates the platform with role-scoped access

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify that `GET /admin/dashboard` returns platform-wide GMV, per-state order counts, SLA/fulfillment metrics and queue depths that reconcile with the seeded data, that `MODERATOR` gets the aggregate subset but no export, and that non-admin roles are refused. | integration | P1 | Yes — Jest + Supertest |

## Preconditions

| # | Precondition |
|---|---|
| 1 | Period `2026-09-01…2026-09-30`: `tech-store` 178,500 YER + store B 272,750 YER ⇒ platform **GMV 451,250 YER**; orders-by-state counts seeded to sum to the period's order total. |
| 2 | SLA seeds: `sla24hEscalations = 3`, `overdueDecisions = 2`, `failedAttempts = 7`, `onTimePercent` computed; queues: `kyc = 4`, `returns = 6`, `disputes = 2`, `topups = 5`; `topVendors` seeded with both stores. |
| 3 | Tokens: `ADMIN`, `MODERATOR`, customer `771234567`, vendor `779876543`; nightly aggregation has run (`relation: "exact"`). |

## Test Data

| Field | Value |
|---|---|
| request | `GET /admin/dashboard?from=2026-09-01&to=2026-09-30` |
| expected GMV | `451250` |
| expected topVendors order | store B (272750) before `tech-store` (178500) |
| export probe | `GET /admin/reports/gmv/export?from=2026-09-01&to=2026-09-30` as moderator vs admin |

## Steps
1. As `ADMIN`, call the dashboard; inspect `gmvYER`, `orders.byState`, `sla`, `fulfillment`, `queues`, `topVendors`, `totalsMeta`.
2. Sum `orders.byState` values; verify `gmvYER` equals the sum of both stores' September sales; verify `topVendors` ordering.
3. As `MODERATOR`, call the dashboard, then the admin `gmv` export; as `ADMIN`, repeat the export; as customer and vendor, call the dashboard.
4. Inspect `Cache-Control` on the dashboard response; call with `from=garbage`.

## Expected Result
- Step 1 → `200 { gmvYER: 451250, orders: { byState: {…} }, sla: { sla24hEscalations: 3, overdueDecisions: 2 }, fulfillment: { onTimePercent, failedAttempts: 7 }, queues: { kyc: 4, returns: 6, disputes: 2, topups: 5 }, topVendors: [ … ], totalsMeta: { gmv: { value: 451250, relation: "exact" } } }` (`API-ANL-006`).
- Step 2 → `Σ byState = ` period order total; `451250 = 178500 + 272750` — platform aggregates reconcile with zero variance (`AC-FR018-02`); `topVendors` sorted descending by sales (`API-ANL-006`, `BR-VND-07` platform view, `AC-FR018-01`).
- Step 3 → Moderator dashboard → `200` (aggregate subset); Moderator export → `403 FORBIDDEN` — Moderators are excluded from exports (`API-ANL-008`, `SEC-REQ-004`); Admin export → `200 text/csv`; customer and vendor → `403 FORBIDDEN` (deny-by-default, `FR-002`).
- Step 4 → `Cache-Control: max-age=30`; malformed range → `400 VALIDATION_ERROR` (`api-conventions.md` §5).
