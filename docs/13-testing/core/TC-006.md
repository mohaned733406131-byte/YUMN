# TC-006 — Refresh rotation is single-use and reuse revokes the session family

| Field | Value |
|---|---|
| Objective | Verify that `POST /auth/refresh` rotates the refresh token on every use and that presenting an already-consumed token returns `401 REFRESH_TOKEN_REUSED`, revokes the entire session family and alerts the user. |
| Level | integration |
| Priority | P1 |
| Automation | Yes — Jest + Supertest |

## Preconditions
- Account `771234567` is logged in (TC-004) with session `sess_A` and refresh token `R1`.
- Security-notification sink is observable (in-app/SMS alert is mandatory and cannot be disabled).
- No other device sessions exist for this user.

## Test Data

| Field | Value |
|---|---|
| Phone | `771234567` |
| First refresh token | `R1` |
| Rotated refresh token | `R2` |
| Session id | `sess_A` |

## Steps
1. `POST /auth/refresh` with `{"refreshToken":"R1"}` and record the new pair.
2. Call `GET /users/me` with the **new** access token from step 1.
3. Replay `POST /auth/refresh` with the already-used `R1`.
4. Call `POST /auth/refresh` with the rotated `R2` (issued in step 1).
5. Call `GET /orders` with the original access token issued at login (pre-refresh).
6. Inspect the user's notification feed for the reuse alert.

## Expected Result
- Step 1 returns `200` with `accessToken2`, `refreshToken = R2`, `expiresIn: 900`, the same `sessionId`; `R1` is marked consumed and can never be redeemed again.
- Step 2 returns `200` — the rotated access token is valid.
- Step 3 returns `401 REFRESH_TOKEN_REUSED`, `retryable:false`; the entire session family (`sess_A`) is revoked.
- Step 4 returns `401 AUTH_INVALID` or `401 SESSION_NOT_FOUND` — rotating forward after reuse detection also fails.
- Step 5 fails once the family is revoked (`401 SESSION_NOT_FOUND` / `TOKEN_EXPIRED` on forced re-verification) — no token from `sess_A` works.
- Step 6 shows one security alert for the reuse event; no other user's sessions are affected.
- An audit entry records the reuse (actor, action, IP, timestamp) without storing token values.
