# TC-093 — Monthly statement arithmetic ties to the ledger and reports payout rollovers

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify that `GET /store/statements/{month}` computes `netPayableYER = gross − refunds − commission ± adjustments` with ledger-backed figures (`ledgerRefs`), that commission reflects the 5–20 % tier, that a sub-1,000 YER month shows a rolled-over payout, and that the statement exports as CSV/PDF with role and format gates. | integration | P1 | Yes — Jest + Supertest |

## Preconditions

| # | Precondition |
|---|---|
| 1 | September 2026 statement for `tech-store`: `grossSalesYER = 178500`, `refundsYER = 12500`, `commissionYER = 17850` (10 % default tier), `adjustmentsYER = 0`; every figure backed by append-only ledger refs. |
| 2 | August 2026 statement: `netPayableYER = 800` with the payout rolled over (below the 1,000 YER minimum). |
| 3 | Tokens: owner `779876543`, staff Viewer `779876550`; `payoutThreshold = 1000` (`BR-ESC-05`). |

## Test Data

| Field | Value |
|---|---|
| September | gross 178,500 − refunds 12,500 − commission 17,850 + adjustments 0 → net **148,150** |
| August | net 800 ⇒ `payout.rolledOver` truthy |
| bad month | `month=2026-13` → expect `400 VALIDATION_ERROR` |
| exports | `?format=csv`, `?format=pdf`, `?format=xls` (invalid) |

## Steps
1. As owner, `GET /store/statements/2026-09`; verify the arithmetic, `ledgerRefs`, `commissionYER` against the store tier.
2. Cross-check the figures against `GET /store/finance/overview?from=2026-09-01&to=2026-09-30` and the ledger feed (Σ variance).
3. `GET /store/statements/2026-08` → inspect `netPayableYER` and `payout`; `GET /store/statements/2026-13`.
4. `GET /store/statements/2026-09/export?format=csv`, then `?format=pdf`, then `?format=xls`; repeat the CSV export as Viewer `779876550`.

## Expected Result
- Step 1 → `200 { month: "2026-09", grossSalesYER: 178500, refundsYER: 12500, commissionYER: 17850, adjustmentsYER: 0, netPayableYER: 148150, payout: { requested, executed, rolledOver }, ledgerRefs: [ … ] }` with `178500 − 12500 − 17850 + 0 = 148150` and `commissionYER = 10 % × gross` (tier 5–20 %, default 10 — `API-ANL-004`, `BR-FIN-04`, `BR-ESC-03`).
- Step 2 → statement figures equal the finance overview period values and tie to the append-only ledger with **zero** unexplained variance — statements never invent fees (`DATA-REQ-007`, `AC-FR018-02`, `analytics.md` §2).
- Step 3 → August shows `netPayableYER: 800` with `payout.rolledOver` truthy — payouts below 1,000 YER roll over (`BR-ESC-05`); `month=2026-13` → `400 VALIDATION_ERROR` (`API-ANL-004`).
- Step 4 → `format=csv` → `200 text/csv` (UTF-8 BOM + attachment + formula guards); `format=pdf` → `200 application/pdf`; `format=xls` → `400 VALIDATION_ERROR`; Viewer → `403 FORBIDDEN` — statement export is Owner-only (`API-ANL-005`, `SEC-REQ-004`).
