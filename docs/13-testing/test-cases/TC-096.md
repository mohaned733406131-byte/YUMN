# TC-096 — CMS page lifecycle: draft, atomic publish, duplicate slug and archive

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify the admin page lifecycle: draft creation (unique slug), draft edits never leaking to the public route, atomic `DRAFT → PUBLISHED` with an audit entry, double-publish refused, duplicate slug refused, and archive removing the public route. | integration | P1 | Yes — Jest + Supertest |

## Preconditions

| # | Precondition |
|---|---|
| 1 | Published page `privacy-policy` exists (public `200`); `GET /admin/pages` contains it with `status: "PUBLISHED"`. |
| 2 | `ADMIN` token seeded; audit log readable via `GET /admin/audit-log`; public reads unauthenticated (`API-CNT-001`). |
| 3 | Slug `ramadan-guide` is unused. |

## Test Data

| Field | Value |
|---|---|
| create | `POST /admin/pages {"slug":"ramadan-guide","title":{"ar":"دليل رمضان","en":"Ramadan Guide"},"bodyBlocks":[{"type":"text","ar":"…","en":"…"}]}` |
| duplicate | same body with `"slug":"privacy-policy"` → expect `409 SLUG_TAKEN` |
| update | `PUT /admin/pages/{id} {"title":{"ar":"دليل رمضان ١٤٤٧","en":"Ramadan Guide 1447"}}` |

## Steps
1. As `ADMIN`, create the `ramadan-guide` draft; then as an anonymous caller, `GET /pages/ramadan-guide`.
2. `PUT /admin/pages/{id}` with the new title; repeat the public read; `GET /admin/pages/{id}` → inspect `history`.
3. `POST /admin/pages/{id}/publish`; repeat the public read; repeat the publish call.
4. Create a second page with slug `privacy-policy`.
5. `DELETE /admin/pages/{id}`; repeat the public read; repeat the delete; `GET /admin/audit-log?targetId={id}`.

## Expected Result
- Step 1 → `201 { id, status: "DRAFT", createdAt }` (`API-CNT-006`); public read → `404 NOT_FOUND` — drafts never resolve publicly (`API-CNT-001`).
- Step 2 → `200 { …page, updatedAt }`; public read still `404`; detail shows `history` entries `{ at, by, action }` for create/update (`API-CNT-007`) — editing a draft never mutates a live page silently (`API-CNT-008`).
- Step 3 → `200 { status: "PUBLISHED", publishedAt, auditId }` (`API-CNT-009`, `BR-PLT-06`); the public read now returns `200 { slug, title: { ar, en }, bodyBlocks, publishedAt, updatedAt }` atomically (no partial state, `AC-FR019-04`); second publish → `409 STATE_CONFLICT` (already published).
- Step 4 → `409 SLUG_TAKEN` — slugs are unique (`API-CNT-006`).
- Step 5 → `204` archive; public read → `404 NOT_FOUND` (soft delete, route stops resolving, `API-CNT-010`); repeated delete → `404 NOT_FOUND`; audit log holds `page.publish` / `page.archive` entries with `actorRole: "ADMIN"` (`SEC-REQ-010`, `AC-FR020-01`).
