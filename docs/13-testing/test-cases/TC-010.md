# TC-010 — Logout revokes one session; logout-all revokes every session

| Field | Value |
|---|---|
| Objective | Verify that `POST /auth/logout` invalidates only the caller's session while `POST /auth/logout-all` clears the whole session registry, and that revoked sessions fail immediately on refresh. |
| Level | integration |
| Priority | P1 |
| Automation | Yes — Jest + Supertest |

## Preconditions
- Account `771234567` is logged in on 3 devices: `sess_WEB` (caller), `sess_ANDROID`, `sess_IOS`.
- Each device holds a valid access + refresh token pair.
- No sessions were revoked in the last minute.

## Test Data

| Field | Value |
|---|---|
| Phone | `771234567` |
| Caller session | `sess_WEB` |
| Other sessions | `sess_ANDROID`, `sess_IOS` |
| Response code for both logout calls | `204` |

## Steps
1. `GET /auth/sessions` and confirm 3 entries with `current: true` on `sess_WEB`.
2. `POST /auth/logout` with `sess_WEB`'s `Authorization` header and its refresh token in the body.
3. Repeat `POST /auth/logout` for `sess_WEB` (idempotency).
4. `POST /auth/refresh` with `sess_WEB`'s refresh token; then `POST /auth/refresh` with `sess_ANDROID`'s.
5. Log back in (session `sess_WEB2`), then `POST /auth/logout-all`.
6. `POST /auth/refresh` with `sess_WEB2`, `sess_ANDROID` and `sess_IOS` refresh tokens.
7. Call `GET /orders` with `sess_ANDROID`'s still-unexpired access token after logout-all.

## Expected Result
- Step 1 returns `total: 3`.
- Step 2 returns `204`; only `sess_WEB` is revoked.
- Step 3 returns `204` again — logout is idempotent for an already-revoked session.
- Step 4: `sess_WEB` fails with `401 SESSION_NOT_FOUND`; `sess_ANDROID` refresh succeeds with `200` — other devices stay signed in.
- Step 5 returns `204` and clears the registry (`GET /auth/sessions` → `total: 0`).
- Step 6: all three refreshes return `401 SESSION_NOT_FOUND` / `AUTH_INVALID`.
- Step 7 fails with `401 SESSION_NOT_FOUND` — access tokens carry the `sid` and die with the session, not only at natural expiry.
- No audit entry is missing for the revocations (actor, action, timestamp, IP).
