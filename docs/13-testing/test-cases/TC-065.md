# TC-065 — Available job list shows only same-zone offers with zone-priced fees

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify that `GET /deliveries/available` returns only open offers for the courier's own domestic zone with the correct zone × weight × method fee, exposes no location coordinates, and refuses offline couriers. | integration | P1 | Yes — Jest + Supertest |

## Preconditions

| # | Precondition |
|---|---|
| 1 | Sub-order `SUB-9C1104` (order `ORD-7F3A21`) is `READY_FOR_PICKUP` in zone `sanaa-center`; package weight 1.4 kg recorded at pack time (band `M`, STANDARD method fee 500 YER). |
| 2 | Courier `790000011` (zones: `sanaa-center`, ONLINE), courier `790000012` (zones: `sanaa-center`, ONLINE), courier `790000013` (zones: `aden-port`, ONLINE) are seeded with tokens. |
| 3 | API base `/api/v1` answers `GET /health/ready` → `200`; no other delivery is open in `sanaa-center`. |

## Test Data

| Field | Value |
|---|---|
| delivery offer | `DLV-4471`, offerVersion `7`, deadlineAt `2026-09-26T18:00:00+03:00` |
| expected fee | `500` YER (zone `sanaa-center` × band `M` × STANDARD) |
| free-shipping seed | checkout with coupon type `free_shipping` already priced `shippingFee = 0` on `ORD-FREE1` |
| courier phones | `790000011`, `790000012`, `790000013` |

## Steps
1. As courier `790000011`, `GET /deliveries/available?zone=sanaa-center&limit=20`.
2. Inspect the item for `DLV-4471`: `zoneSlug`, `weightBand`, `offeredFee`, `offerVersion`, `pickupPoint`, `dropoffDistrict` — and scan the whole body for `lat`/`lng`/`latitude`/`longitude`/`accuracy` keys.
3. As courier `790000013` (aden-port), repeat step 1 with `?zone=sanaa-center`, then with `?zone=aden-port`.
4. As courier `790000011`, `PUT /courier/availability {"availability":"OFFLINE"}` then repeat step 1.
5. Compare `offeredFee` with the seeded shipping price list and with `ORD-FREE1` (free-shipping coupon) totals.

## Expected Result
- Step 1 → `200 { items: [ { deliveryId: "DLV-4471", subOrderId: "SUB-9C1104", zoneSlug: "sanaa-center", pickupPoint: { governorate: "SANA'A", district: "SANA'A CENTER", line1: "..." }, dropoffDistrict: "SANA'A CENTER", weightBand: "M", offeredFee: 500, offerVersion: 7, deadlineAt: "2026-09-26T18:00:00+03:00" } ], page: {...} }` — fee = f(zone, weight, method) (`AC-FR015-01`, `BR-SHP-01`).
- Step 2 → zero location keys anywhere in the payload (`BR-SHP-05`, `C-16`); no live customer position is present.
- Step 3 → `200` with `items: []` for the foreign zone (an `aden-port` courier never receives `sanaa-center` offers — `BR-SHP-04` same-zone eligibility, `C-17`); no offer data of the other zone leaks.
- Step 4 → `409 COURIER_OFFLINE` (`retryable: true`), nothing returned; availability stays `OFFLINE`.
- Step 5 → `offeredFee = 500` YER for the priced shipment and `ORD-FREE1` shows `shippingFee = 0` when a `free_shipping` coupon applies (`BR-SHP-01`).
