# TC-005 — Five consecutive failed logins lock the account for 15 minutes

| Field | Value |
|---|---|
| Objective | Verify that the 5th consecutive failed login locks the account for 15 minutes with `423 ACCOUNT_LOCKED`, that the lock event is logged, and that a successful login resets the counter. |
| Level | integration |
| Priority | P1 |
| Automation | Yes — Jest + Supertest |

## Preconditions
- Verified account `771234567` exists with 0 failed login attempts and is not locked.
- Audit/log sink is queryable for lock events; clock source is controllable for the 15-minute window.
- Login rate limit (10/min/IP) is raised for this test run so throttling does not mask the lockout.

## Test Data

| Field | Value |
|---|---|
| Phone | `771234567` |
| Wrong password used 5 times | `Wrong#2026x` |
| Correct password | `Yumn#2026a` |
| Lock duration | 900 seconds (15 minutes) |

## Steps
1. `POST /auth/login` with the wrong password 4 times and record each status/body.
2. `POST /auth/login` with the wrong password the 5th time.
3. `POST /auth/login` with the **correct** password while the lock is active.
4. Inspect the response headers of step 2 for `Retry-After`.
5. Query the audit log for lock events tied to `771234567` in the test window.
6. Advance the clock (or wait) 15 minutes, then `POST /auth/login` with the correct password.

## Expected Result
- Attempts 1–4 each return `401 INVALID_CREDENTIALS` with `retryable:false`.
- Attempt 5 returns `423 ACCOUNT_LOCKED` with `error.retryAfterSeconds` between 890 and 900 and `Retry-After` header set to the same value.
- The locked attempt with the correct password also returns `423 ACCOUNT_LOCKED` — credentials are not evaluated during the lock.
- Exactly one audit entry exists per lock: actor, action `LOGIN_LOCKED`, entity (user id), timestamp, IP; the entry is append-only.
- After 15 minutes login with the correct password returns `200` with a fresh token pair and the failure counter is reset to 0.
- The account is not locked again until 5 new consecutive failures occur.
