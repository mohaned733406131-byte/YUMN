# TC-059 — Commission base excludes VAT and shipping at release

## Objective

| Objective | Level | Priority | Automation |
|---|---|---|---|
| Verify that commission is computed at release as (line subtotal after coupon discount) × tier rate, excluding VAT and shipping, per BR-ESC-03 read together with BR-FIN-01/02. | unit | P1 | Yes — Jest (commission service unit tests) |

## Preconditions

| # | Precondition |
|---|---|
| 1 | Escrow engine exposes the commission inputs: discounted line subtotal, VAT, shipping fee, tier rate. |
| 2 | Vendor tier is the platform default 10% (500–2000 bps band, `BR-ESC-03`). |
| 3 | Coupon `FIX1000` (fixed 1,000 YER) is active and applicable to the cart. |

## Test Data

| Field | Value |
|---|---|
| gross subtotal | 12,000 YER (`هاتف سامسونج`) |
| coupon | `FIX1000` → discount 1,000 YER |
| discounted base | 11,000 YER |
| VAT / shipping | 15% × 11,000 = 1,650 YER; shipping 500 YER (untaxed) |
| sub-order total | 11,000 + 1,650 + 500 = **13,150 YER** |

## Steps
1. Build a captured sub-order with the totals above and reach `DELIVERED` with code `482913`.
2. Advance the clock 7 days and run `b07.escrow.release` with no dispute or return open.
3. Read `b07.escrow.commission_base_yer`, `commission_rate_bps`, `commission_amount_yer`.
4. Compute the three plausible wrong values: 10% × 13,150 (total) = 1,315; 10% × 11,500 (base + shipping) = 1,150; 10% × 13,650 (total + shipping) = 1,365.
5. Run the same fixture with a 90% discount coupon (base 1,200 YER) and re-check the band and rounding.

## Expected Result
- `commission_base_yer = 11000`, `commission_rate_bps = 1000`, `commission_amount_yer = 1100` (half-up to whole YER, `BR-FIN-05`).
- Posted commission equals **none** of 1,315 / 1,150 / 1,365 — VAT (1,650) and shipping (500) are outside the base (`BR-FIN-01`: shipping untaxed; `BR-ESC-03`: line subtotal after coupon).
- Payable credit = 13,150 − 1,100 = 12,050 YER; escrow row satisfies `ck_escrow_released_complete`.
- 90% fixture: base 1,200, commission 120 YER; rate stays within 500–2000 bps.
- Re-running the calculation with identical inputs returns the same integers — no floats in money paths (`BR-PAY-10`).
